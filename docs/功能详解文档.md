# 轻量 OA 系统 — 功能详解文档

> 版本：v3.0 ｜ 日期：2026-10-10
> 定位：轻量化中小企业版。仅保留「门户 + 审批 + 考勤 + 通讯录 + 文档 + **即时通讯**」六大业务 + 系统基础管理。
> 配套：《系统设计文档.md》《技术实现文档.md》《接口说明文档.md》《性能与优化建议.md》。

本文档描述**新增/增强**功能的功能点、业务规则与角色边界，是开发与验收的依据。
现有功能（仪表盘、员工/部门管理、公告管理、个人中心基础项）不重复描述，只列受影响处的**增强点**。

---

## 0. 角色与权限总览

| 角色 | 标识 | 说明 | 功能边界 |
|---|---|---|---|
| 超级管理员 | `ADMIN` | 全局管理 | 全部管理功能 + 系统基础管理 |
| 部门管理员 | `DEPT_ADMIN` | 部门级管理 | 本部门员工/账号/通讯录维护、本部门考勤报表、文档/审批的部门授权 |
| 普通员工 | `EMPLOYEE` | 日常办公 | 门户、消息、公告阅读、审批发起/办理、考勤打卡、通讯录只读、文档权限内操作 |

> 数据范围：`DEPT_ADMIN` 的所有管理动作限定在**本部门（含直属子部门）**；`ADMIN` 无范围限制。
> 越权控制：前端按角色裁剪菜单；后端拦截器校验 `/api/admin/**`（ADMIN）、`/api/dept-admin/**`（DEPT_ADMIN 或 ADMIN）；Service 层按部门范围二次过滤。

## 1. 工作台门户模块

### 1.1 首页工作台（增强）
- 欢迎横幅保留现有设计（姓名、工号、部门、入职日期）。
- 新增**审批卡片**：待我审批数、我发起的进行中数、今日考勤状态。
- 新增**待办/已办**快捷列表：最近 5 条待我审批、最近已办，点击直达审批单详情。
- 快捷入口扩展：发起审批、待办审批、消息中心、通讯录、文档中心、打卡。
- 布局：左右分栏，左侧常用功能+待办列表，右侧最新公告+提醒。

### 1.2 消息中心
- 消息类型：`1` 审批提醒、`2` 系统通知、`3` 公告提醒。
- 消息为**按接收人落库**（站内信模型）。
- 能力：分页列表、未读 tab、单条标记已读、全部已读、未读数角标（顶栏轮询）。
- 触发点：审批归属到人时（待办提醒）、审批结果（通过/驳回/撤回通知发起人）、公告发布成功时。

### 1.3 通知公告（增强）
- 公告新增**附件**支持：发布时上传多个附件，详情页展示可下载。
- 公告新增**查看记录**：员工打开详情即记录已读（每人每条一次）。
- 公告新增**已读统计**：管理员列表/详情展示 已读人数 / 应读人数 / 未读名单。
- 员工公告中心页新增“我的查看状态”标记。

### 1.4 个人中心（增强）
- 新增**头像上传**（图片，大小受系统设置限制）。
- 新增**个人操作记录**：查询我自己的登录、提交/办理审批等操作日志（分页）。
- 修改密码、个人资料沿用现有。

## 2. 流程审批模块（核心）

### 2.1 表单自定义
- 表单（form）由**字段集合**构成，支持字段类型：文本、数字、日期、单选、多选、附件。
- 管理员可新建自定义表单；**预置 4 类内置表单**：请假申请、加班申请、出差申请、物品领用申请。
- 字段属性：名称、类型、是否必填、（选项类）候选值、（数字类）单位等。
- 表单设计器交互：左侧字段类型面板「点击/拖拽」→ 中部字段列表（可上下移、编辑、删除）→ 实时预览渲染动态表单。
- 员工发起审批时：选择已启用流程 → 按表单字段动态渲染填写 → 提交。

### 2.2 流程配置
- 每个流程绑定一个表单，定义**审批节点链**。
- 节点类型：`APPROVAL`（审批）、`END`（结束，隐含）。
- 审批人指定方式：
  - `ROLE` 指定角色（如 ADMIN）
  - `DEPT_LEADER` 发起人所属部门负责人（部门管理员）
  - `SPECIFIC_USER` 指定用户
  - `OWN_DEPT` 发起人部门
- **串行审批**：节点按序号逐个流转，前一个通过后自动派发下一个。
- **分支条件审批**：审批节点可配置一个条件（`字段 = / > / 包含 值`），满足时走向分支节点，否则走向下一节点（实现“请假 ≤3天 → 直属负责人；>3 天 → 加走人事负责人”这类场景）。

### 2.3 预置模板
| 模板 | 表单字段 | 默认审批链 |
|---|---|---|
| 请假申请 | 请假类型（事假/病假/年假/调休）、开始日期、结束日期、请假天数（数字）、事由（文本）、附件 | 发起人部门负责人<br/>（若天数>3 分支 → 人事主管） |
| 加班申请 | 加班日期、开始时间、结束时间、加班时长（数字）、事由 | 部门负责人 |
| 出差申请 | 出差城市、开始日期、结束日期、天数、事由、附件 | 部门负责人 → 行政负责人 |
| 物品领用 | 物品名称、数量、用途、附件 | 部门负责人 → 行政负责人 |

### 2.4 审批操作与状态
状态机（流程实例 status）：
```
DRAFT(草稿/撤回后) → APPROVING(审批中) → APPROVED(已通过)
                                      → REJECTED(已驳回)
                                      → WITHDRAWN(已撤回)
```
任务节点状态（flow_task.status）：`PENDING → APPROVED / REJECTED / WITHDRAWN / TRANSFERRED`

| 操作 | 角色 | 规则 |
|---|---|---|
| 提交 | 发起人 | 校验必填字段；创建实例 + 首节点任务；通知第一审批人 |
| 同意 | 当前节点审批人 | 记录意见；置当前任务通过 → 派发下一节点；末节点 → 实例 APPROVED；联动考勤（见第 3 章）|
| 驳回 | 当前节点审批人 | 实例 REJECTED，流程结束，通知发起人 |
| 转办 | 当前节点审批人 | 将当前待办转给他人，原任务记录 TRANSFERRED，生成新 PENDING 任务；链路上留痕 |
| 撤回 | 发起人 | 仅 `APPROVING` 状态允许；实例回 WITHDRAWN，所有待办关闭 |
| 加意见 | 当前节点审批人 | 仅作为补充意见记录，不改变状态 |

### 2.5 审批查询
- 我发起的：状态筛选、发起时间、标题搜索。
- 待我审批：所有 PENDING 任务。
- 已审批：我处理过的任务（含同意/驳回/转办）。
- 审批历史链路：实例时间线——每一步（提交/同意/驳回/转办/撤回）的操作人、动作、意见、时间，从 `flow_comment` 渲染。

### 2.6 审批归档
- 实例永久保存（不做物理删除，提供归档视图），`DELETE` 仅标记逻辑删除。
- 归档单保留：表单值 + 附件 + 完整审批链路，可随时回看。
- 管理员可查看全部归档；发起人/审批人可查看各自相关的单。

## 3. 考勤管理模块

### 3.1 打卡规则配置（管理员）
- 单条生效规则：上班时间、下班时间、打卡定位点（经纬度 + 半径）、休息日（如每周六日）。
- 管理员可启用/停用规则；启用定位校验时可设置打卡允许偏差。
- 节假日安排暂以“休息日清单”维护（不含法定节假日自动计算，轻量取舍）。

### 3.2 打卡管理
- 员工端「上下班打卡」：提交打卡类型（上班/下班）、时间、定位（经纬度 + 地址文案）。
- 定位校验：距离打卡点超出半径 → 拒绝；未开启定位校验 → 跳过距离判断。
- 状态判定：
  - 上班：≤规定上班时间 `NORMAL`；迟到 `LATE`。
  - 下班：≥规定下班时间 `NORMAL`；早退 `EARLY_LEAVE`。
  - 缺卡：有上无下 / 有下无上 → `MISSING_IN / MISSING_OUT`（由初次生成记录补齐状态）。
- 休息日/考勤规则停用 → 不打生成缺卡记录；重复打卡更新当天记录。

### 3.3 请假/加班联动（审批 → 考勤）
- 审批通过且流程类别为 **请假**：按 `请假天数` 自动生成对应日期 `LEAVE` 考勤记录（跳过休息日）。
- 审批通过且流程类别为 **加班**：按加班时段生成 `OVERTIME` 记录（出勤明细 + 工时用于报表）。
- 已存在当天记录时覆盖状态为联动值；联动数据带 `source=FLOW_LINK`。

### 3.4 考勤记录
- 个人：按「月份」查看本人每日考勤明细（打卡时间、状态）。
- 管理员：按月查看全员明细。

### 3.5 考勤报表（管理员，月）
- 聚合指标：应出勤天数、实际出勤、迟到次数、早退次数、缺卡次数、请假天数、加班次数/小时、旷工天数。
- 导出：月度 Excel（采用 UTF-8 BOM 的 Excel 兼容 CSV，无需第三方依赖，Excel 双击可开）。
- 部门管理员：仅导出本部门范围。

## 4. 组织通讯录模块

### 4.1 组织架构与岗位
- 员工档案新增「岗位 position」字段（编辑/新增时填写，注册时可选）。
- 组织架构维护沿用现有部门树 + 员工管理，增加岗位展示。

### 4.2 企业通讯录（全登录用户）
- 按部门树展示，部门下罗列员工：姓名、岗位、手机号、邮箱。
- 普通员工只读；管理员/部门管理员额外展示账号状态等信息。

### 4.3 账号管理
- 复用员工管理：新增账号（自动建档+建号）、禁用/启用、重置密码、注销。
- 部门管理员：仅能操作本部门账号（新增员工必须落在本部门，禁用/重置限本部门）。

### 4.4 权限控制
- 员工只能浏览通讯录；维护动作仅在管理端；部门管理员限定本部门数据范围。

## 5. 文档中心模块

### 5.1 目录管理
- 文件夹为多级树；管理员（或具备权限者）创建子目录、重命名、删除（仅空目录可删）。
- 根目录「公共文档」内置不可删。

### 5.2 文件操作
- 上传（重名自动保留两者或提示覆盖）、下载、删除、重命名、在线预览。
- 预览：图片/PDF 走浏览器直接渲染；其余类型仅提供下载。
- 上传大小受系统设置 `附件大小限制` 约束。

### 5.3 权限管控（文件夹级）
- 每条文件夹可配置授权：授权对象（部门/个人）、授权类型（可读/可编辑）。
- 权限继承：子目录未配置时继承父目录；根目录默认“全员可读、仅管理员可编辑”。
- 校验：读 → 至少 READ 或 EDIT；上传/重命名/删除/授权 → 需 EDIT。
- 文件夹作者的默认 EDIT（保证可维护自己创建的目录）。

### 5.4 文件版本
- 覆盖上传 = 生成新版本：保留历史文件实体，`doc_file_version` 记录历次文件名、大小、上传人、时间。
- 文件页展示版本历史，可下载任意历史版本。

### 5.5 文件检索
- 按文件名模糊搜索（树内任意层级命中）。

## 6. 系统基础管理（管理员）

### 6.1 角色权限管理
- 角色分档：超级管理员 `ADMIN` / 部门管理员 `DEPT_ADMIN` / 普通员工 `EMPLOYEE`。
- 管理员可**晋升指定员工为部门管理员**（或收回）；角色变更即时生效（前端菜单 + 后端拦截）。
- 功能权限以“角色→可见菜单/接口”为粒度（轻量 RBAC，不做细粒度按钮权限）。

### 6.2 操作日志
- 记录：登录/登出、员工/部门管理、公告管理、审批动作、文件操作、系统配置变更。
- 字段：操作人、类型、对象、详情、IP、时间。管理员分页检索；个人中心可查“我的操作记录”。

### 6.3 系统设置
- `message_push_enabled`：消息推送总开关（关闭后各业务不再产生站内消息）。
- `attachment_max_size`（MB）：附件/头像上传大小上限。
- 设置保存即生效；修改写入操作日志。

## 8. 设计简化说明（轻量化取舍，已确认）

本系统定位「中小企业轻量版」，以下功能点采用**简化实现**，与完全版能力的差异在此明确标注。
如需升级为完整实现，可按「后续演进方向」推进。

| 编号 | 需求点 | 本项目实现 | 与完整版的差异 | 后续演进方向 |
|---|---|---|---|---|
| S1 | 表单自定义「拖拽」 | 字段面板**点击添加** + 列表**上下排序** | 非鼠标拖拽交互，但字段增删与顺序调整能力等价 | 引入拖拽库（如 vuedraggable）改为拖拽布局 |
| S2 | 组织架构「岗位」 | 员工档案上的**自由文本岗位字段** | 无独立「岗位字典」实体，不做岗位与角色的绑定 | 新增 `sys_position` 岗位表 + 岗位-部门关联 |
| S3 | 角色「功能权限」 | **角色 → 菜单/接口** 粒度（超管/部门管理员/员工） | 无逐按钮/逐功能点的权限勾选配置 | 引入权限点表 + 角色-权限点关联（RBAC 细粒度） |
| S4 | 考勤报表「月度 Excel」 | 导出 **Excel 兼容 CSV**（UTF-8 BOM，双击可直接打开） | 非 `.xlsx` 二进制格式，无多 Sheet/单元格样式 | 引入 Apache POI 生成 `.xlsx` |
| S5 | 公告附件编辑 | 编辑时**仅追加**附件；单个附件删除有独立接口（`DELETE /admin/notices/{id}/attachments/{aid}`），未在编辑弹窗内暴露 | 编辑弹窗内不能直接移除已发布附件 | 编辑弹窗内增加附件列表与移除操作 |
| S6 | 移动端操作 | **响应式 Web**（Element Plus 自适应布局，浏览器打开即用） | 非独立 App / 小程序，定位打卡依赖浏览器 Geolocation | 封装 H5/小程序端，接入原生定位与拍照 |
| S7 | 考勤节假日 | 以**休息日清单**（每周固定休息日）维护 | 不含法定节假日自动计算与调休 | 接入节假日表 / 工作日历 |

> 说明：S1–S7 均为**有意识的范围控制**，不影响对应需求的正常使用；相关实现细节见《技术实现文档.md》第 7 节。

## 9. 即时通讯模块（v3 新增）

### 9.1 会话
- 会话分两类：**单聊**（`SINGLE`）与**群聊**（`GROUP`）。
- 单聊去重：任意一方发起的两人会话复用同一会话（去重键 `minUserId-maxUserId`）。
- 群聊：多选成员后新建，默认群名「群聊（N人）」，可自定义群名。
- 会话列表按最近活跃时间倒序，展示对端名称/群名、最后一条消息、未读数。

### 9.2 消息
- 消息类型：当前为文本（`TEXT`），单条上限 2000 字符。
- 发送后**实时推送**：正在打开该会话的双方收到会话频道消息；各成员的会话列表/未读数通过定向队列刷新。
- 历史消息：按会话倒序分页（默认每页 30 条），前端按时间正序展示。

### 9.3 未读与已读
- 未读数按成员已读游标（`last_read_msg_id`）计算，仅统计他人发送且晚于游标的消息。
- 打开会话即标记已读（回写游标为会话内最新消息 ID）。
- 顶栏未读红标与消息中心共享同一状态，**全部已读后红标立即清除**。

### 9.4 入口
- 收件箱旁的独立「即时通讯」菜单。
- **通讯录**支持点击单人发起单聊、勾选多人发起群聊，一键进入会话。

### 9.5 权限与边界
- 仅会话成员可读写该会话；非成员访问返回 403。
- 单聊需对端账号存在且启用；群聊成员去重并包含发起人。

## 10. v3 体验增强点（对 v2 功能的改进）

| 增强点 | 说明 |
|---|---|
| 头像上传与展示 | 上传后由组件以带权 blob 拉取渲染，解决受保护头像接口直连 401 的问题；个人中心可换头像 |
| 请假/出差时长 | 起止时间精确到分钟（DATETIME），时长由起止**自动计算**并只读展示，不再由员工手填天数；审批分支 `请假天数 > N` 仍按计算结果生效 |
| 消息未读红标 | 未读数统一由共享状态维护，全部已读即清，避免红标残留 |
| 通讯录发起会话 | 通讯录从「只读名录」升级为「可发起单聊/群聊」的办公入口 |

> 相关库表、接口与实现见《技术实现文档.md》第 8–9 章、《接口说明文档.md》第 10 章。
